# Opscompass Studio
This is the GitHub repository for distribution of the Opscompass Studio. A desktop tool to facilitate interactive data gathering for monitored Opscompass database resources.  Currently we only supoprt Oracle with this tool, but future releases may include SQL Server and others.

This tool is still in the early release candidate stage and may not be entirely stable yet.

Here is the Opscompass KB reference to the user's guide<br/>
https://kb.opscompass.com/knowledge/how-do-i-use-opscompass-studio
